# PashuMauli

Offline-first livestock health surveillance and emergency communication platform.

## Start here
1. Read `MASTER_SPEC.md`.
2. Read `ARCHITECTURE.md`.
3. Read `CLAUDE.md`.
4. Read the relevant files in `docs/`.
5. Start Claude Code from this repository root.
6. Ask Claude Code to inspect specifications and create `IMPLEMENTATION_PLAN.md` before writing application code.

## Components
- `backend/` FastAPI + PostgreSQL/PostGIS + Redis
- `mobile/` Flutter + SQLite + TFLite
- `dashboard/` React/Next.js + Leaflet
- `docs/` specifications
- `scripts/` development/demo utilities

## Principle
Build one connected system, not independent demo applications.
